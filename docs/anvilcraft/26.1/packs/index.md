# 数据包与资源包

配方放在服务端 `data/<命名空间>/recipe/`，资源包的模型、翻译和游戏内手册放在 `assets/<命名空间>/`。要覆盖内置配方，复用它的命名空间和相对路径；另取 ID 会新增同类型配方。改配方或标签后执行 `/reload`，动态注册表变更在重新打开世界时加载。

## 建立独立包

把 `pack.mcmeta` 放在 ZIP 或包目录的根层，和 `data` 或 `assets` 同级。Minecraft 26.1.2 的数据包格式是 101.1，资源包格式是 84.0。下面的元数据用于只面向该游戏版本的数据包。

```json
{
  "pack": {
    "description": "铁砧工艺配方调整",
    "min_format": [
      101,
      1
    ],
    "max_format": [
      101,
      1
    ]
  }
}
```

创建客户端资源包时，将上下限均改为 `[84, 0]`。
