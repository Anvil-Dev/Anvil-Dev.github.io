ModMathFunctions ​

public class ModMathFunctions

类型声明

本模组注册进 anvillib:function 数据包注册表的数学函数。 条目写在 data/anvilcraft/anvillib/function/<名字>.json，由 runData 生成。 命名空间必须用 anvilcraft ：runData 只写出 modId 命名空间下的条目 （NeoForge 的 RegistriesDatapackGenerator 按命名空间过滤），注册到 anvillib 下 会静默不落盘。表达式里因此要写全名 anvilcraft:double(x)；flat 文本按路径优先查注册表， 全名引用能正常解析。

成员签名实现与调用约定源码
public static final ResourceKey<IFunction> DOUBLE把传入的维修材料消耗翻倍，作为「通用维修材料」未指定消耗时的默认值。 形参名与调用点绑定的具名传入值 $(cost) 同名，函数体既能写 $(cost)*2， 也能写成 flat 文本 "x*2"——第 0 个传入值就是它。
初值 ResourceKey.create( LibRegistries.FUNCTION_KEY, AnvilCraft.of("double") )		字段
public static void bootstrap(BootstrapContext<IFunction> ctx)执行 ctx.register(ModMathFunctions.DOUBLE, ModMathFunctions.doubleFunction())方法
public static CustomFunction doubleFunction()翻倍函数的定义。 函数体里的 $(a) 在求值期从调用点的具名传入值里取，所以构造调用表达式时 传 IExpression#ref(String) ref(a) 即可——该引用是按位绑下形参后再按名字取的， 位置和名字都能对上。形参个数仍按位校验，实参不能省。
末尾返回 CustomFunction.of( List.of("a"), LibBuiltInFunctions.MULTIPLY.call(IExpression.ref("a"), IExpression.of(2)) )
调用处 RepairMaterialFrostMaterialPredicate		方法
