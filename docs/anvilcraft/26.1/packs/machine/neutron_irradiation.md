# 中子辐照

为中子辐照工序定义物品转换，并通过炼药锅谓词限制反应环境。

在数据包中建立 `data/example/recipe/neutron_irradiation/example.json`。游戏按 `type` 选择序列化器，这个文件的配方 ID 是 `example:neutron_irradiation/example`。

## 配方示例

```json
{
  "type": "anvilcraft:neutron_irradiation",
  "ingredients": [
    {
      "items": "#c:ingots/uranium"
    }
  ],
  "results": [
    {
      "count": 6,
      "id": "anvilcraft:plutonium_nugget"
    }
  ]
}
```

[内置配方原文件](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/generated/resources/data/anvilcraft/recipe/neutron_irradiation/plutonium_nugget.json)

## 字段与取值

根对象的 `type` 必填，填写 `anvilcraft:neutron_irradiation`。

| `ingredients` | 物品原料谓词数组 | 可省略，默认 `[]` | 参与匹配的原料列表 [声明](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/main/java/dev/dubhe/anvilcraft/recipe/anvil/wrap/NeutronIrradiationRecipe.java#L34) |
| `results` | 带概率的物品栈数组 | 可省略，默认 `[]` | 各次输出使用的结果列表 [声明](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/main/java/dev/dubhe/anvilcraft/recipe/anvil/wrap/NeutronIrradiationRecipe.java#L37) |
| `fluid` | `FluidStackPredicate.CODEC` | 可省略，默认 `EMPTY_PREDICATE` | 炼药锅的流体匹配条件 [声明](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/main/java/dev/dubhe/anvilcraft/recipe/component/HasCauldronSimple.java#L66) |
