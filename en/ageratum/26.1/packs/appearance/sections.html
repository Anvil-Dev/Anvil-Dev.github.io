Directory Tree, Bookmarks, and Actions ​

Put chapters with many labels into a scrollable directory and pin a few common actions. Below is a directly usable layout file; ageratum:fullscreen provides the sidebar hosting all three sections.

json
{
  "extends": "ageratum:fullscreen",
  "tree": {
    "height": "55%",
    "indent_per_level": 12,
    "hover_shift": 0,
    "collapse_mode": "collapsed",
    "marquee": { "enabled": true, "speed": 28, "pause_ms": 900, "gap": 20 }
  },
  "bookmarks": { "height": "fill", "weight": 1, "show_add_button": false },
  "actions": {
    "height": "auto", "direction": "horizontal", "spacing": 6,
    "align": "bottom", "buttons": ["add", "return", "close"]
  }
}
FieldTypeOptionality, Default & Purpose
Section visibleBooleanOptional, default true. The hosting panel must also list the section in sections.
Section heightNumber or stringOptional. Positive number for fixed height, "45%" for percentage, "auto" for natural height, "fill" to share remaining space. tree and bookmarks default to fill; actions defaults to auto.
Section weightPositive numberOptional, default 1. Multiple fill sections divide remaining height by weight. Fixed and auto heights scale down proportionally if they exceed available height.
tree.indent_per_level, hover_shiftNon-negative integerDefaults 10 and 5; sets per-level indent and horizontal shift on hover. Set to 0 to disable either effect.
tree.collapse_modeStringOptional. auto uses the screen's default expansion rule; expanded and collapsed set initial expanded or collapsed state.
tree.pinned_parent, scroll_hintBooleanBoth default true; control pinned parent chapter hints and directory scroll hints.
tree.marquee, bookmarks.marqueeObjectLong-title scrolling settings. enabled defaults true; speed is positive, defaulting to 30 logical pixels/sec; pause_ms defaults 800; gap defaults 24 logical pixels.
bookmarks.show_add_buttonBooleanOptional, default true. When hiding the add button in bookmarks, you can place add in actions.
actions.buttonsEnum string arrayDefaults to ["close","share","return","dark"]; also supports add. Array order sets display order; duplicates or unknown buttons are ignored.
actions.direction, alignEnum stringdirection defaults to vertical and also accepts horizontal. align defaults to top and also accepts bottom.
actions.spacingNon-negative integerOptional, default 10; controls spacing between action buttons.
