public final class GitHubApiClient

类型声明

GitHub API 客户端。 负责通过 GitHub REST API 解析默认分支最新 commit 并下载仓库 zip 包。 请求携带 OAuth APP 的 Client ID（#CLIENT_ID），并在 api.github.com 失败时依次回退到内置的社区代理前缀。 代理可用性随时可能变化，因此每个 host 的响应都会经过严格校验 （状态码、Content-Type、JSON/zip 魔数），不满足即视为失败并继续下一个。

GitHubRepoCache ​

public final class GitHubRepoCache

类型声明

GitHub 仓库缓存：负责下载指定 commit 的 zip 包并解压到 caches/ageratum/repos/<user>-<repo>/ 目录。 解压时会剥离 zip 内不确定的顶层目录（<user>-<repo>-<sha>）， 使缓存目录直接对应仓库根。使用 .commit 标记文件记录已缓存 commit， 相同 commit 直接命中缓存，避免重复下载。 所有下载/解压均在异步线程执行，调用方通过 CompletableFuture 消费结果。
