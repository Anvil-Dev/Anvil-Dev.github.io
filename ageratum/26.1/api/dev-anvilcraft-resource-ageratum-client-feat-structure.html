public final class AgeratumStructureTemplateManager

类型声明

客户端结构模板管理器。 在资源重载时扫描并缓存所有资源包中 assets/<namespace>/ageratum/ 目录下的 .nbt 文件。 模板 Identifier 格式为 namespace:relative/path（相对于 ageratum/ 目录，不含 .nbt 后缀）。 例如：assets/minecraft/ageratum/village/house.nbt → minecraft:village/house

成员签名实现与调用约定源码
