快速烹饪的配方构建器 ​

配方分别处理食材和炼药锅液体。将液体谓词及消耗量写在根对象。

提交前检查物品原料列表和产物列表。两者都至少需要一项，空列表会触发 IllegalArgumentException。 构建器校验

在附属模组的数据生成提供器中调用 generate，传入当前 RecipeOutput。运行数据生成后，配方 ID 为 example:fast_cooking/guide，文件位于 data/example/recipe/fast_cooking/guide.json。

java
package dev.example.recipebuild;

import dev.dubhe.anvilcraft.recipe.anvil.wrap.FastCookingRecipe;
import net.minecraft.data.recipes.RecipeOutput;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.world.item.Items;

public final class FastCookingRecipes {
    public static void generate(RecipeOutput destination) {
        FastCookingRecipe.builder()
            .requires(Items.MUD)
            .result(Items.CLAY)
            .save(destination, ResourceLocation.fromNamespaceAndPath("example", "fast_cooking/guide"));
    }
}

实现采用上游 FastCookingRecipeLoader.init 中的一条实际配方链。 原始配方调用

入口调用约定
generate在 datagen 期间接收当前输出对象，一次调用写入一个配方。
save显式指定配方键。同一轮生成中，每个 ID 只应写一次。

生成文件的字段约定 ​

字段JSON 类型或解码器必填与默认值用途
ingredients物品原料谓词数组可省略，默认 []参与匹配的原料列表
results带概率的物品栈数组可省略，默认 []各次输出使用的结果列表
fluidFluidStackPredicate.CODEC可省略，默认 EMPTY_PREDICATE炼药锅的流体匹配条件
consume整数可省略，默认 0本次工序的消耗设置
transformTRANSFORMS_CODEC可省略，默认 []工序结束时的流体变化
chance数值可省略，默认 1.0f触发概率
ignited布尔值可省略，默认 false匹配点燃状态
