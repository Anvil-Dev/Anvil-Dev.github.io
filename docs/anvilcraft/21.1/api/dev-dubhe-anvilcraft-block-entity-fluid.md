## AbstractPipeBlockEntity

` public abstract class AbstractPipeBlockEntity extends BlockEntity `

[类型声明](https://github.com/Anvil-Dev/AnvilCraft/blob/6a4cde43b4ece65b765137a7aab145b9b4c002bf/src/main/java/dev/dubhe/anvilcraft/block/entity/fluid/AbstractPipeBlockEntity.java#L17)

管道 BlockEntity 抽象基类。 重构后管道本体（直管/弯管/节点） 不再是方块实体 ——它们是纯方块， 由流体网络（dev.dubhe.anvilcraft.api.fluid.network.FluidPipeNetwork） 从相邻容器 flood-fill 时顺带发现。本基类现仅供仍需 BlockEntity 的 PumpBlockEntity（耗电机器，需 tick 与状态同步）复用通用的方块更新工具。


## AbstractPipeCheckValveBlockEntity

` public abstract class AbstractPipeCheckValveBlockEntity extends BlockEntity `

[类型声明](https://github.com/Anvil-Dev/AnvilCraft/blob/6a4cde43b4ece65b765137a7aab145b9b4c002bf/src/main/java/dev/dubhe/anvilcraft/block/entity/fluid/AbstractPipeCheckValveBlockEntity.java#L38)

管道止逆阀数据的 BlockEntity 基类 —— 止逆功能 与管道结合 的存储载体。 止逆阀不是独立方块，而是管道 某个连接面上的单向流动约束 ： 每个装有止逆阀的面记录一个"允许流出的世界方向"（#baseFlow）， 流体只能沿该方向穿过这个面。普通管道仅在 HAS\_CHECK\_VALVE 为 true 时 创建具体 BE；玻璃管道因流体显示需要常驻 BE，并复用这里的止逆阀数据。 方向语义 baseFlow.get(face) = 无红石信号时该面允许的流出方向（通常即 face 本身， 表示"沿臂向外流出"）。收到红石信号（#powered）时全部反向，见 #effectiveFlow。 无 ticker 纯数据 BE，不参与 tick；流体分配由 dev.dubhe.anvilcraft.api.fluid.network.FluidPipeNetwork 扫描时读取本 BE 的面约束完成。

## ControlValveBlockEntity

` public class ControlValveBlockEntity extends BlockEntity implements MenuProvider `

[类型声明](https://github.com/Anvil-Dev/AnvilCraft/blob/6a4cde43b4ece65b765137a7aab145b9b4c002bf/src/main/java/dev/dubhe/anvilcraft/block/entity/fluid/ControlValveBlockEntity.java#L57)

控制阀的 BlockEntity。存储流体过滤（白名单）和最大流速，供流体网络分配时门控。 过滤 白名单直接以 FluidStack 存储（ 不经桶物品 ，因为部分流体如蜂蜜无对应桶）， 由玩家在 GUI 中手动放入桶 / 从 JEI 拖入流体设置，此为 单流体白名单 。 过滤格还可放入 过滤器物品 以一次过滤多种流体：此时逐个读取过滤器内容， 把其中的流体桶（以及附魔书——液态魔咒无对应桶）解析为流体，并按过滤器的 白名单 / 黑名单模式决定放行或拦截。放入过滤器后单流体白名单不再参与判定。 未设置任何过滤 → 允许所有流体通过。 流速 #getMaxRate() ∈ \[0, 管道流速上限\] mB/tick，只限制每 tick 流过本阀门的流体上限， 不是最低起送量；白名单只放行已标记的流体，不会用其他液体补足流速。

泵的 BlockEntity。消费 32kW 电力，为流体网络提供输出侧 +10 / 输入侧 -10 的等效高度势场。 重构后泵 不再自行搬运流体 ：它只作为网络中的一条"有向势能边"，实际流体 分配由 dev.dubhe.anvilcraft.api.fluid.network.FluidPipeNetwork 统一执行。 本 tick 仅刷新电力/红石/过载状态并据此决定 #canPump()。 工作状态判定： 有红石信号 → 关闭（阻断网络连接） 电网过载 → 关闭（阻断网络连接） 正常供电 → 工作（提供势场） 方向映射：dev.dubhe.anvilcraft.block.state.Orientation#getDirection() 返回输出方向， 该侧等效高度 +10；反向（输入侧）-10。
