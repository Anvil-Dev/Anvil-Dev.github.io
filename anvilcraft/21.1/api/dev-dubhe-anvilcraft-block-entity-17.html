StoragePortConsolidatorBlockEntity ​

public class StoragePortConsolidatorBlockEntity extends BlockEntity implements IItemHandlerHolder, IFluidHandlerHolder, IStoragePort

类型声明

仓储端口整合器方块实体。 沿面相邻的仓储端口收集整个端口阵列，把各端口缓存的并集作为物品能力暴露给外部物流， 并把相连的流体端口按「一个端口一格」暴露为流体能力，读写都直通该端口的储罐； 接上集装箱时还会并入该存储名下登记的其它流体端口，避免外接端口只对集装箱可见。 物品能力的相连关系只穿过端口，不跨集装箱 / 存储站，因此集装箱两侧没有直接相连的 端口阵列不会互通；流体能力则按存储归属合并，同一存储名下的端口互通。 流体能力的槽位顺序按「维度 + 坐标」固定，但该槽位集合仅服务端权威： 客户端只看到面相邻端口，数量可能少于服务端。 标记端口的缓存排在未标记端口之前，按槽位插入只访问对应缓存槽， 按槽位遍历（如 ItemHandlerHelper#insertItem）即可填满整个阵列的缓存； 相连端口标记物品的仓储输出槽也会并入物品能力，同一仓储的同种标记只暴露一次。 未连接其他端口且直接接触唯一仓储核心时，物品能力在自身的 32 格缓存之外以只读方式 暴露该仓储的全部槽位：外部只能从仓储取出物品，输入先进入缓存，再由服务端按性能墙并入仓储。 右键为「塞入」：单击把手持物品塞入，双击把身上对应端口标记的物品全部塞入； 手持流体容器时先尝试倒入相连的、已在存放同种流体的流体端口。
