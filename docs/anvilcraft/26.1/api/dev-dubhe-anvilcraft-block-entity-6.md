[类型声明](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/main/java/dev/dubhe/anvilcraft/block/entity/CorruptedBeaconBlockEntity.java#L48)

腐化信标方块实体。 光束改为锻星砧风格的四棱锥暗色光束（见 corrupted-beacon-beam-rework）： - \`beamHeight\` 记录光束顶端世界 Y（第一个阻挡方块处，无阻挡则为最高建筑高度）， 由渐进扫描（每 tick 最多 10 格）持续更新，不做平滑插值； - LIT 仅取决于基座等级（levels &gt; 0），不再因上方有实心方块而熄灭。
