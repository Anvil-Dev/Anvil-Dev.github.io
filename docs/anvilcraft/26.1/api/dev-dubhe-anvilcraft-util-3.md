一个用于处理各种炼药锅逻辑的工具类，集中了各种各样的特判代码。&lt;s&gt;把特判集中到一个类里面总比在各种类里面到处特判要好吧&lt;/s&gt;<br>使用约定 本类中所有的名为 \`cauldronContent\` 的方法参数代表“炼药锅内容物”，传入的是一种非空的炼药锅方块。 它是一个类似于“流体”的抽象概念，但由于细雪炼药锅装的不是流体，我们不能用 \`Fluid\` 作为参数。 本类的大部分方法在 \`cauldronContent\` 方法参数不是一种炼药锅时不会抛出异常，而是返回一些默认值。
