## CraterDensityFunction

` public record CraterDensityFunction(NoiseHolder noise, List<Layer> layers) implements DensityFunction `

[类型声明](https://github.com/Anvil-Dev/AnvilCraft/blob/7ac05a76988c98454c0384513fcab44d9da4cf88/src/main/java/dev/dubhe/anvilcraft/worldgen/CraterDensityFunction.java#L29)

环形山密度函数：按多个图层（不同尺度）以网格单元随机撒布环形山， 山脊为高斯凸起，坑内为平底洼地。 坑与坑重叠时（包括跨图层）按优先级从旧到新依次施加： 新坑以坑心处的旧地形为基准重塑自身轮廓（坑底下挖、山脊隆起）， 山脊带内完全替换旧地形、外侧平滑混入旧地形， 因此相交处不会叠出双倍高墙，也不会残留旧坑轮廓或抬出凸台。 地形修饰仅作用于水平方向（忽略 y），竖向衰减在噪声设置 JSON 中组合。<br>参数 ` noise ` 种子化噪声，用于每个单元的「是否存在 / 中心抖动 / 半径 / 强度 / 优先级」随机参数<br>参数 ` layers ` 环形山图层列表，通常从大到小排列
