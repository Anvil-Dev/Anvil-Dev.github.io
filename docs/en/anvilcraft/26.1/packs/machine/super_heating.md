# Super Heating

Writes input items and furnace environment into a super-heating recipe. Outputs use weighted item stacks.

Create `data/example/recipe/super_heating/example.json` in your data pack. The game selects the serializer by `type`. The recipe ID for this file is `example:super_heating/example`.

## Recipe Example

```json
{
  "type": "anvilcraft:super_heating",
  "ingredients": [
    {
      "items": "anvilcraft:end_dust"
    }
  ],
  "results": [
    {
      "id": "minecraft:end_stone"
    }
  ]
}
```
