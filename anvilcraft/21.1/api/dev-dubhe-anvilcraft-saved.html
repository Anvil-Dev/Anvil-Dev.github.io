WormholeInterfaceStates ​

public class WormholeInterfaceStates extends BetterSavedData

类型声明

Global saved data that stores the canonical state for each wormhole interface pair (logistics items &amp; fluid tanks). Each pair — identified by the wormhole network's paramsHash, the relative block offset, and the interface type — receives a deterministic UUID. All CFAs sharing the same wormhole network group access the same canonical state, ensuring they behave like a single unified interface. Laser interfaces are NOT stored here; their sync is purely computational (sum inputs, split among outputs) each tick.
