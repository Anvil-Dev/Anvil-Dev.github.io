# 数据包与资源包

配方放在服务端 `data/<命名空间>/recipe/`，资源包的模型、翻译和游戏内手册放在 `assets/<命名空间>/`。要覆盖内置配方，复用它的命名空间和相对路径；另取 ID 会新增同类型配方。改配方或标签后执行 `/reload`，动态注册表变更在重新打开世界时加载。
