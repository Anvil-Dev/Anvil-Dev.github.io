# 天体锻造砧与恒星演化

天体锻造砧通过槽位、种子和供电状态搜索天体。服务端方块实体持有搜索状态、历史和巨构处理器；附属模组可以读出这些状态、转存天体或提供新的巨构。

- [发起搜索、判断失败原因](./search)从服务端交互到结果落定。
- [磁盘与奇点水晶快照](./snapshot)说明支持的载体、返回副本和极端天体限制。
- [根据质量和光谱查找演化轨道](./evolution)用于模拟器、调试面板和重载后的读取。
- [注册巨构与处理器](./megastructures)给新巨构设置建造前提、轨道、材料和运行行为。

天体合成和搜索素材的 JSON 见[天体与神庙配方](../packs/celestial/)。恒星轨道、事件和覆盖矩阵的资源路径见[恒星数据格式](../packs/stars/)。
