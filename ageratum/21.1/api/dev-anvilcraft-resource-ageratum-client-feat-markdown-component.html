类型声明

一次内联样式匹配结果，保存起止标签与样式 / 文本生成逻辑。 此类可保存两类工厂之一： 传统的 BiFunction<Style, Matcher, Style>：用于在解析时返回一个新的 net.minecraft.network.chat.Style，随后由解析器对标签内部文本递归解析并应用该样式； 新的 TriFunction<String, Style, Matcher, FormattedText>：直接基于原始 内部字符串 (innerText)、父样式与匹配器生产最终的 net.minecraft.network.chat.FormattedText， 这使得解析器可以一次性生成多段文本（例如按字符的渐变色片段）。 当两者都存在时优先使用 textFactory；通常只会有其一被设置（由工厂方法创建）。
