在手册中检查预览方块 ​

结构卡片能用来标明多方块机器里某个端口的位置。玩家先调好可见层数，再点击预览模型：左键选中方块并弹出提示，右键则会在指南界面里打开该方块的 GUI 预览。注意这里读的是客户端预览世界里的方块，不会打开服务端机器的容器。拾取和 GUI 预览入口

组件会在松开鼠标时判断这次操作是点击还是拖拽。只有光标在预览区内、移动距离没超过点击阈值、松开键和按下键一致，而且没点到控制按钮时，才会结合相机视角、平移量和可见层范围去拾取方块。如果之前选中的方块后来被藏到了可见层范围外，组件会清掉旧提示；右键点中但这个方块没有可显示的菜单时，提示会变成“没有 GUI”。点击边界 · 提示更新

如果附属组件手里已经有模板、选中的模板内坐标和屏幕锚点，可以直接复用指南自带的 GUI 预览。下面的桥接方法会接收所属组件对象，传入同一个对象就能让预览记住是谁打开了它。你可以根据返回值决定是显示菜单，还是退回提示文本。

java
package dev.example.blueprint;

import dev.anvilcraft.resource.ageratum.client.feat.markdown.component.extend.MDNBTStructureComponent;
import dev.anvilcraft.resource.ageratum.client.gui.GuideScreen;
import net.minecraft.core.BlockPos;
import net.minecraft.world.level.levelgen.structure.templatesystem.StructureTemplate;

public final class BlueprintInspection {
    public static boolean open(GuideScreen screen, MDNBTStructureComponent owner,
                               StructureTemplate template, BlockPos selected,
                               float anchorX, float anchorY) {
        return screen.structureGuiPreview().open(owner, template, selected, anchorX, anchorY);
    }
}
参数或接口作用使用时机
GuideScreen.structureGuiPreview()获取屏幕持有的预览控制器使用正在显示的指南实例。该屏幕每帧调用控制器的 beginFrame 和 render，并优先分派预览覆盖区域的输入。
owner、template、selected所属组件、完整模板、被选中的模板方块使用同一次拾取对应的模板和坐标。右键没有命中时，原组件跳过打开操作。
anchorX、anchorY鼠标所选方块中心的屏幕锚点原组件通过投影变换将方块中心转换到屏幕坐标后再打开；两值不应使用世界坐标。

GuideScreen 的预览控制器 · 组件的右键调用

同一组件还公开了 renderExportButton(MDRenderContext)，供集成模块绘制 16 × 16 的主题按钮和悬停提示。其左上角为 (context.maxX() - 21, 25)。点击处理和导出操作由集成模块提供。本分支的 Ageratum 注册了打开指南、打开 GitHub 指南和分享指南三种载荷。按钮绘制 · 网络注册
