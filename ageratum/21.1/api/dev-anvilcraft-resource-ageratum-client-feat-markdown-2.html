public class MarkdownParser

类型声明

Markdown 解析器。 负责将原始 Markdown 文本按块级语义拆分为一组 MDComponent， 并在解析阶段处理引用链接、代码块、列表、表格、引用块等结构。 同时支持两种扩展语法： ::: namespace:location ... ::: 冒号语法 <namespace:location>...</namespace:location> 和 <namespace:location/> 标签语法 扩展组件通过 NeoForge Custom Registry ageratum:extension_component_factory 注册。 解析器也支持通过 #registerComponentParser(int, MDComponentParser) 注入行级组件解析器。
