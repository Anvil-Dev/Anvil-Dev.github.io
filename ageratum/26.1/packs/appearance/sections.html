目录树、书签与操作区 ​

把标签较多的章节交给可滚动目录，固定几个常用操作。下面是可直接引用的布局文件，ageratum:fullscreen 提供三个分区所在的侧栏。

json
{
  "extends": "ageratum:fullscreen",
  "tree": {
    "height": "55%",
    "indent_per_level": 12,
    "hover_shift": 0,
    "collapse_mode": "collapsed",
    "marquee": { "enabled": true, "speed": 28, "pause_ms": 900, "gap": 20 }
  },
  "bookmarks": { "height": "fill", "weight": 1, "show_add_button": false },
  "actions": {
    "height": "auto", "direction": "horizontal", "spacing": 6,
    "align": "bottom", "buttons": ["add", "return", "close"]
  }
}
字段类型可选性、默认值与用途
各区 visible布尔可选，默认为 true。所在面板还要把该区列入 sections。
各区 height数值或字符串可选。固定高度用正数，比例用 "45%"，"auto" 按自然高度，"fill" 参与剩余空间分配。目录与书签默认 fill，操作区默认 auto。
各区 weight正数可选，默认为 1。多个 fill 分区按权重划分剩余高度。固定和自动高度超过可用高度时等比例缩小。
tree.indent_per_level、hover_shift非负整数默认为 10、5，指定每层缩进和鼠标悬停时的横移量。设 0 可取消对应效果。
tree.collapse_mode字符串可选。auto 使用界面的默认展开规则，expanded 与 collapsed 指定初始展开或折叠。
tree.pinned_parent、scroll_hint布尔均默认 true。控制固定父章提示和目录滚动提示。
tree.marquee、bookmarks.marquee对象长标题滚动设置。enabled 默认 true，speed 为正数，默认每秒 30 个逻辑像素。pause_ms 默认 800 毫秒，gap 默认为 24 个逻辑像素。
bookmarks.show_add_button布尔可选，默认 true。隐藏书签分区的添加按钮时，可将 add 放进操作区。
actions.buttons枚举字符串数组默认 ["close","share","return","dark"]。另有 add。数组顺序即显示顺序，重复或未知按钮忽略。
actions.direction、align枚举字符串方向默认 vertical，也接受 horizontal。对齐默认 top，还接受 bottom。
actions.spacing非负整数可选，默认 10，控制操作按钮之间的间距。
