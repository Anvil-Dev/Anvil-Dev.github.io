物品栈组件 ​

配方产物和战利品均能携带组件。在物品栈的 components 对象里以注册 ID 为键。例如下面的结果栈显式写入储能值。

json
{
  "id": "anvilcraft:magnet_ingot",
  "count": 1,
  "components": {
    "anvilcraft:stored_energy": 16
  }
}

disk_data ​

DiskData

字段JSON 类型或解码器必填与默认值用途
tagCompoundTag.CODEC必填写入的标签内容 声明

structure_disk_data ​

StructureDiskData

字段JSON 类型或解码器必填与默认值用途
file字符串必填结构存储文件标识 声明
name字符串必填名称 声明
uuidUUIDUtil.CODEC必填关联结构的唯一标识 声明
directionDirection.CODEC可省略，默认 Direction.NORTH结构朝向 声明
sizeX整数必填X 轴尺寸 声明
sizeY整数必填Y 轴尺寸 声明
sizeZ整数必填Z 轴尺寸 声明
upsideDown布尔值可省略，默认 false是否上下翻转结构 声明
autoRotate布尔值可省略，默认 true是否允许自动旋转蓝图 声明

saved_entity ​

SavedEntity

字段JSON 类型或解码器必填与默认值用途
tagCompoundTag.CODEC必填写入的标签内容 声明
isMonster布尔值必填记录捕获对象是否为怪物 声明

heliostats_data ​

HeliostatsData

字段JSON 类型或解码器必填与默认值用途
pos三整数坐标必填方块位置 声明

structure_data ​

StructureData

字段JSON 类型或解码器必填与默认值用途
minX整数必填X 轴下界 声明
minY整数必填Y 轴下界 声明
minZ整数必填Z 轴下界 声明
maxX整数必填X 轴上界 声明
maxY整数必填Y 轴上界 声明
maxZ整数必填Z 轴上界 声明

multiphase ​

Multiphase

字段JSON 类型或解码器必填与默认值用途
phasesPhase.CODEC数组必填已记录的相位 声明
active_phase整数必填当前生效的相位 声明
merciless布尔值可省略，默认 false无情属性的配置 声明
idCodec.PASSTHROUGH必填注册 ID 声明

Phase

字段JSON 类型或解码器必填与默认值用途
custom_nameComponentSerialization.FLAT_CODEC可省略自定义名称文本 声明
repair_cost整数必填铁砧修复费用 声明
enchantmentsItemEnchantments.CODEC必填附魔数据 声明

box_contents ​

BoxContents

字段JSON 类型或解码器必填与默认值用途
amulets物品栈对象数组必填已存护符列表 声明
totems物品栈对象数组必填已存图腾列表 声明
selection整数必填当前选择的位置 声明

filter_contents ​

FilterContent

字段JSON 类型或解码器必填与默认值用途
listItemStack.OPTIONAL_CODEC数组必填过滤器物品列表 声明
include_components布尔值必填匹配过滤物品时是否比较组件 声明
deny_list布尔值必填启用排除列表 声明
black_list布尔值必填旧式黑名单开关 声明

pill_box_contents ​

PillBoxContents

字段JSON 类型或解码器必填与默认值用途
pills物品栈对象数组必填已存药丸 声明

over_limit_item_container_contents ​

Slot

字段JSON 类型或解码器必填与默认值用途
slot整数 0 至 255必填槽位编号 声明

comrades ​

Comrades

字段JSON 类型或解码器必填与默认值用途
playersUUIDUtil.CODEC数组可省略，默认 []记录的玩家列表 声明

StorageRef

字段JSON 类型或解码器必填与默认值用途
typeIStorageType.HOLDER_CODEC必填分派到对应实现的类型 ID 声明
idUUIDUtil.CODEC可省略注册 ID 声明

terminal_binding ​

TerminalBinding

字段JSON 类型或解码器必填与默认值用途
idUUIDUtil.CODEC可省略注册 ID 声明

crafting ​

CraftingStorage

字段JSON 类型或解码器必填与默认值用途
stonecutter_inputItemStack.OPTIONAL_CODEC必填切石机输入 声明
crafting_inputItemStack.OPTIONAL_CODEC数组必填合成网格的原料 声明
stonecutter_selected整数可省略，默认 0选中的切石配方 声明
last_opened布尔值可省略，默认 false最近打开的存储界面 声明
auto_fill布尔值可省略，默认 false是否自动填充合成原料 声明
to_storage布尔值可省略，默认 false是否输出到存储 声明
